# ecommerce-sales-performance-dashboard
E-commerce sales and performance dashboard

Overview

This project analyzes e-commerce sales transactions using SQL and Power BI to uncover revenue trends, customer purchasing behavior, and product performance insights.

The dashboard was developed to support business decision-making through interactive reporting and KPI monitoring.

Tools Used:
SQL Server
Power BI
DAX
Microsoft Excel
